# Sai Deekshitha Telukuntla — Developer Portfolio

A responsive, static portfolio website for a Full-Stack .NET Developer with emphasis on user-centered interfaces, accessibility-aware UI practices, .NET APIs, and Azure delivery.

## Preview locally

1. Download or clone this repository.
2. Open `index.html` in a browser.

No build step or framework installation is required.

## Publish with GitHub Pages

1. Create a new public repository on GitHub named `your-github-username.github.io` (replace with your actual GitHub username), or create a regular repository and enable Pages in Settings.
2. Upload `index.html`, `styles.css`, `script.js`, and this README to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for the deployment to finish. GitHub will display the published site URL in the Pages settings.

## Personalize before publishing

- Confirm the displayed name, email address, role, experience duration, and technologies.
- Add your real GitHub profile URL and LinkedIn URL when ready.
- Replace the illustrative project case studies with sanitized, original code samples or screenshots you are authorized to share.
- Do not upload confidential client code, internal screenshots, data, credentials, or proprietary architecture.
- Only describe accessibility training, certifications, audits, and WCAG conformance if you can substantiate them. The current site describes accessibility-aware practices and explicitly does not claim a third-party audit.

## Accessibility notes

The page includes a skip link, semantic landmarks, accessible navigation labels, visible keyboard focus, reduced-motion support, responsive layouts, and expandable project notes. These measures do not substitute for a full manual and automated accessibility audit.
