# Portfolio Project Pack

Three original demo projects to add to the GitHub portfolio.

## Projects
1. `accessible-task-dashboard` — interactive responsive UI demo with filters, task creation, completion, dark mode, keyboard focus, and live status announcements.
2. `dotnet-api-starter` — ASP.NET Core minimal API with CRUD endpoints, validation, Swagger, and in-memory repository.
3. `azure-cicd-reference` — Azure DevOps YAML starter pipeline and secure deployment guidance.

## Add to GitHub
Create a folder for each project in the repository and upload that project's files. Keep the portfolio's `index.html`, `styles.css`, and `script.js` at the repository root so GitHub Pages can publish the main portfolio.

These are demo projects. Test the .NET project locally before claiming it as production-ready; do not add confidential client data or imply these demos were client work.
