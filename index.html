04 / ACCESSIBILITY

Accessibility is part of the build—not a last-minute fix.

My UI development approach considers accessibility from the start and aims to align with WCAG 2.1 AA principles.

  • ✓ Semantic HTML and logical heading order
  • ✓ Labels, instructions, and useful error messages
  • ✓ Keyboard navigation and visible focus states
  • ✓ Responsive layouts and clear interaction states
  • ✓ Manual review plus automated checks where available

Accessibility claims should be backed by testing on each specific project; this portfolio does not claim a formal third-party audit or certification.
